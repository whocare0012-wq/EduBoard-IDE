# EduBoard IDE 使用说明

这是开发预览，目前没有实体开发板验收。编辑和保存无需账号或联网。

## 三个开发模式

编辑区上方直接选择“图形化”“C++”或“Python”。切换保留当前项目的两份文本和积木布局，不会清空代码。保存会一起保存全部内容；重新打开 `.eduboard.json` 即可恢复。新建、打开其他项目和关闭窗口会保护未保存的更改，Ctrl+S 保存。

同一项目的 C++ 和 Python 分别保留光标、选区、滚动位置和撤销/重做记录，往返图形化模式也不会清空文本编辑历史。“采用生成代码”替换文本后可撤销。新建或重新打开项目会开始新的编辑会话；编辑历史与光标位置不写入项目文件。

图形化模式可选择“积木生成语言”，右侧为只读预览。“采用生成代码”把结果写入当前语言的文本工作区；已有不同文本时会先确认替换。直接切换到文本模式优先恢复已有文本。修改文本不会自动修改积木，也不会自动翻译成另一种语言。

首次切换到一个尚无文本的语言时，若项目有积木，则用该语言的生成代码初始化；否则使用 Blink 初始代码。“新建图形化示例”创建一个新项目，有未保存内容时先提示。

## 面板与小窗口

- 输出面板随窗口高度调整，可通过“收起/展开”保留或腾出编辑空间。编译、语法检查、运行及连接串口时会展开输出。
- 拖动编辑区与输出区之间的分隔线调整输出高度；聚焦分隔线后，上/下方向键调整，Home/End移到边界，双击恢复自动高度。
- 图形化编辑区宽度不足760px时默认隐藏代码预览，可点击“显示代码预览”手动展开；再次点击可隐藏。宽度按编辑区计算，折叠侧栏也会影响自动布局。
- 积木与预览之间的分隔线支持左右拖动、左/右方向键和Home/End。双击恢复默认比例及自动显示策略。手动尺寸和显示选择在当前应用会话中保留。
- 小窗口的Python输出栏使用简短的REPL标题，按钮保留可访问名称。

## 项目文件

使用 `Blink` 等英文项目名（字母或下划线开头，最多 63 字符）。上级目录和代码可包含中文。

保存 EduBoard 项目生成 `Blink/Blink.eduboard.json`，并导出当前工作区的 `Blink.ino` 或 `main.py`。JSON 保存两个文本工作区和积木，是完整项目；单独打开 `.ino` / `.py` 只进入文本编辑。把独立文本扩展为多模式项目时会生成同名项目目录，原始文件继续保留。再次保存 JSON 项目会刷新当前语言的源文件导出。

## Arduino C++

1. 在工具链设置选择 Arduino CLI；工具包用户同时选择对应 YAML 配置。
2. 安装 ESP32 核心，刷新开发板列表并选择实际板型的 FQBN。核心和示例依赖的安装按钮需要联网；离线使用须提前配置。
3. 编译前保存，查看实时输出；可取消长任务。
4. 编译并上传前选择真实串口、核对板型和 LED 引脚。上传会覆盖板上程序。编译成功后才上传，源文件或目标变化会使已有编译结果失效。
5. 选择波特率后打开串口；当前示例为 115200。更改端口或波特率前关闭串口，设备操作会先释放已有连接。

开发板示例包含 LED、按钮、DHT11、SH1106 和 NeoPixel。接线说明在侧栏展开，传感器库可通过“安装示例依赖（联网）”安装。积木变量目前为数值变量，语句须放入“启动时”或“不断重复”。未连接积木有警告，重复入口或无效灯珠序号有错误；修复后才能编译。

## Python / MicroPython

1. 按 [MicroPython 配置](micropython.md) 安装 Python 工具环境，在工具链设置中选择该环境的 `python.exe`。
2. 切换 Python，选择实际固件 / 板型。C3 新建示例默认 LED GPIO3、按钮 GPIO5；已有代码或积木的引脚不会因切换板型而自动修改。
3. “检查语法”只用主机 Python 解析文本，不会在电脑执行用户程序，也不能证明 `machine` 等设备模块兼容。
4. 选择真实串口后，“运行到设备”把保存的程序发送到设备执行，并重连 REPL；不会将程序写入设备启动文件。查看输出确认运行结果。
5. “连接 REPL”可发送交互命令，“中断设备程序”发送 Ctrl+C / Ctrl+B。首次输出可能在重连前产生，应结合设备验证。
6. 设备文件操作支持根目录列表、上传当前程序、下载、删除。上传和删除会先确认；路径使用 `/main.py` 等英文绝对路径。上传 `main.py` 或 `boot.py` 会影响启动行为。
7. 固件安装需选择目录中指定版本的官方文件，先通过格式和 SHA-256 校验。点击擦除刷入后还会显示板型、串口、文件和完整摘要供确认；实际设备不匹配或启用安全启动 / 加密时会拒绝刷写。此操作清空全部设备文件。

MicroPython 积木支持 GPIO、算术 / 变量 / 控制流、延时、输出、DHT11 和 NeoPixel。SH1106 积木暂不支持 MicroPython，保留工作区并显示错误，可切回 C++ 或修改积木。

接线说明展示“当前板型下新建所选示例”的默认引脚，与新建示例共用配置。修改积木或文本后，以实际程序引脚为准。C3 LED与按钮示例分别明确显示GPIO3及GPIO5；Arduino示例仍使用其独立的经典ESP32默认值。

## 错误定位

- 点击“检查语法”“编译”或“编译并上传”后，任务完成时会在对应代码中显示错误波浪线，悬停查看原因。Python 检查仍只解析语法，不执行电脑上的用户程序；这些标记来自本次检查，不是输入时的自动检查。
- 输出中带文件、行列信息且属于当前主程序的错误可点击，也可用 Tab 聚焦后按 Enter。编辑器会切回对应 C++ / Python 文本并把光标放到报错处；生成程序的错误回到图形化模式的只读代码预览。小窗口会自动展开该预览。
- 修改对应文本、采用生成代码、修改积木或更改 Arduino 目标后，旧定位会失效；再次检查获取新结果。新建或打开项目清除先前会话的标记和链接，旧日志仍可阅读。重新检查只保留该缓冲区最近一次检查的定位。
- 库文件、其他源文件以及没有明确文件行号的错误保留为普通日志，避免跳到当前代码的错误位置。原始错误实时显示一次，结束时追加结果；取消、超时、缺少工具或 REPL 重连失败的补充提示仍会显示。“清空”只清除输出，不修改代码或现有标记。

## 排错

- 未找到工具：选择独立安装的工具程序，确认其环境和所需包齐全。
- Arduino 目标为零：检查 YAML 中的数据目录和 ESP32 核心安装位置。
- 编译失败：点击带下划线的错误日志跳转，修复后重新编译；无跳转的日志需检查完整文件路径、板型与库依赖。
- 串口失败：关闭其他串口程序，检查 USB 数据线、驱动、端口和启动模式。
- 取消后端口未释放：等待任务结束；若无法关闭旧进程，应用会拒绝后续设备操作，重启后再试。
- 固件被拒绝：核对 [固件矩阵](micropython.md)，不要改文件内容或使用另一型号 / 版本代替。

通过的软件检查见 [开发记录](progress.md)，实物验收见 [硬件验收表](hardware-acceptance.md)。
