# EduBoard IDE 开发预览使用说明

这是开发预览，尚未完成真实 ESP32 和全新 Windows 机器验收。项目编辑不需要账号或联网。

1. 新建后编辑 Blink 程序，把 `LED_PIN` 改为自己板子的 LED 引脚。
2. 点击保存或按 Ctrl+S，使用 `Blink` 等英文项目名。程序会保存到 `Blink/Blink.ino`；上级目录可以包含中文。
3. 打开时选择同名目录中的主 `.ino` 文件。新建、打开和关闭会提示尚未保存的更改。
4. 展开“工具链设置”，选择另行安装的 Arduino CLI 程序。离线工具包用户还需要选择对应的 CLI YAML 配置文件。
5. 安装对应的 ESP32 核心后刷新开发板列表，并选择实际板型的 FQBN。应用内安装按钮会联网下载官方核心；离线课堂应提前部署。
6. 点击编译，查看实时输出。长时间没有进展时可取消任务。
7. 上传前检查板型、USB 数据线、驱动和串口。上传会覆盖板上现有 Arduino 程序。只有成功编译的当前程序和同一目标才允许上传。
8. 在输出区选择波特率，打开串口查看输出。当前示例使用 115200。更改波特率前先关闭串口。再次上传会先释放串口。

## 常见问题

- 未找到工具：在工具链设置中选择 `arduino-cli.exe`，并确认该工具能单独运行。
- 已安装目标为零：检查 CLI 配置的数据目录，以及 ESP32 核心是否安装到这个目录。
- 编译失败：先查看最后一段错误输出，检查板型和所需库。
- 串口访问失败：关闭其他串口程序，检查数据线、USB 驱动、设备管理器和开发板启动模式。
- 取消后无法释放端口：应用会拒绝开始新的设备操作；关闭占用串口的程序或重启应用后再试。
